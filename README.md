# کلیدبان (Kelidban Authenticator)
### رمزساز دوعاملی امن، کاملاً آفلاین و متن‌باز (TOTP/HOTP)
**Secure, Zero-Telemetry, Fully Offline 2FA Authenticator PWA**

---

## 🌟 قابلیت‌ها و ویژگی‌های کلیدی (Key Features)

1. **کاملاً آفلاین و بدون سرور (Zero-Network Runtime)**:
   - پس از اولین بارگذاری، برنامه بدون نیاز به اینترنت و حتی در حالت Airplane Mode کار می‌کند.
   - هیچ سروری وجود ندارد، هیچ ترکینگ یا تحلیلی (Analytics) ارسال نمی‌شود و هیچ داده‌ای از دستگاه خارج نمی‌شود.
2. **رابط کاربری فارسی با چیدمان استاندارد RTL و تم دارک مدرن**:
   - قلم وزیرمتن (Vazirmatn) به‌صورت ۱۰۰٪ سلف‌هاست و بدون وابستگی به CDN در پروژه بارگذاری شده است.
   - پشتیبانی کامل از تاریخ و تقویم جلالی (شمسی) در نام فایل‌های پشتیبان و نمایش زمان‌ها.
   - رابط کاربری تمیز و بهینه‌سازی شده برای موبایل بدون پیچیدگی و تنظیمات اضافه.
3. **امنیت در سطح استانداردهای بانکی و نظامی (Defense in Depth)**:
   - **عدم ذخیره کلیدها در متن خام (No Plaintext Secrets)**: هیچ رازی به‌صورت متن خام ذخیره نمی‌شود.
   - **مشتق‌گیری کلید قوی (PBKDF2)**: بیش از ۶۰۰,۰۰۰ دور درهم‌سازی با الگوریتم SHA-256 و سالت ۱۶ بایتی تصادفی با کیفیت کریپتوگرافیک (`crypto.getRandomValues`).
   - **رمزنگاری متقارن با احراز اصالت (AES-256-GCM)**: کل پایگاه داده گاوصندوق با نانس (IV) یک‌بارمصرف ۱۲ بایتی برای هر ذخیره‌سازی رمزنگاری می‌شود.
   - **کلید فقط در حافظه رم (In-Memory Key Lifetime)**: کلید رمزگشایی فقط در رم نگهداری شده و در صورت قفل دستی، تایم‌اوت عدم فعالیت یا پنهان شدن تب، صفر (`zeroBuffer`) و پاک می‌شود.
   - **عدم استفاده از localStorage**: تمام داده‌های حساس منحصراً در IndexedDB رمزنگاری‌شده نگهداری می‌شوند.
   - **درخواست ذخیره‌سازی دائمی (`navigator.storage.persist()`)**: جلوگیری از پاک‌سازی خودکار کش توسط مرورگر در شرایط کمبود حافظه.
   - **سیاست‌های امنیتی سخت‌گیرانه (Strict CSP & Headers)**: `default-src 'self'`, مسدودسازی اسکریپت‌های درون‌خطی و `eval`, مسدودسازی فریم‌بندی (`X-Frame-Options: DENY`), و `Referrer-Policy: no-referrer`.
4. **روش‌های متنوع افزودن حساب**:
   - اسکن کد QR با دوربین از طریق `getUserMedia` و `BarcodeDetector` به همراه کتابخانه پشتیبان `jsQR`.
   - چسباندن آدرس‌های استاندارد `otpauth://totp/...` یا `otpauth://hotp/...`.
   - بارگذاری و پردازش فایل تصویر کد QR (PNG/JPG/WebP).
   - ورود دستی مشخصات حساب (نام، ارائه‌دهنده، کلید Base32، نوع، الگوریتم، تعداد ارقام و دوره تناوب).
5. **پشتیبانی از استانداردهای رسمی OTP**:
   - استاندارد RFC 6238 برای TOTP (الگوریتم‌های SHA-1, SHA-256, SHA-512 با دوره‌های ۳۰ یا ۶۰ ثانیه و ۶ یا ۸ رقم).
   - استاندارد RFC 4226 برای HOTP مبتنی بر شمارنده با دکمه ایجاد کد بعدی.
   - پاک‌سازی خودکار کلیپ‌بورد پس از ۳۰ ثانیه در صورت اجازه مرورگر.
   - حلقه بدون تاخیر همگام با ساعت سیستم عامل با شمارش معکوس دایره‌ای انیمیشنی.
6. **پشتیبان‌گیری و بازیابی جامع (Backup & Restore)**:
   - صدور فایل رمزنگاری‌شده AES-256-GCM با رمز عبور اختصاصی و تاریخ جلالی در نام فایل (`kelidban-backup-1405-08-12-1430.enc`).
   - بازیابی و واردسازی فایل‌های پشتیبان رمزگذاری‌شده کلیدبان.
   - واردسازی فایل‌های پشتیبان نرم‌افزارهای محبوب **Aegis Authenticator** و **2FAS Authenticator** و فهرست‌های متنی ساده `otpauth://`.
7. **نصب PWA روی صفحه اصلی (Installable PWA)**:
   - مانیفست کامل وب اپلیکیشن با نام فارسی، آیکون‌های استاندارد و Maskable برای Android و iOS Safari.
   - سرویس ورکر خودکار برای کش ۱۰۰٪ دارایی‌ها و پشتیبانی آفلاین پایدار.

## 🛡️ مدل امنیتی و محدودیت‌های برنامه‌های وب (Security Model & Limitations)

این برنامه بالاترین سطح امنیت فنی ممکن را در بستر مرورگر پیاده‌سازی کرده است. با این حال، کاربران و توسعه‌دهندگان باید تفاوت‌های بنیادین میان یک وب اپلیکیشن (PWA) و یک برنامه بومی (Native Sandbox) را در نظر داشته باشند:

### ۱. مواردی که کلیدبان در برابر آن‌ها محافظت می‌کند:
- **نشت داده‌های دیسک**: اگر فایل دیتابیس IndexedDB توسط فرد دیگری یا نرم‌افزارهای فایل خوانده شود، به دلیل رمزنگاری با کلید AES-256 مشتق‌شده از گذرواژه ۶۰۰k-دور، بدون داشتن گذرواژه اصلی امکان دسترسی به داده‌ها وجود ندارد.
- **حملات شبکه‌ای و شنود (Man-in-the-Middle)**: برنامه کاملاً در سمت کلاینت اجرا شده و کلیدها هرگز به هیچ شبکه‌ای ارسال نمی‌شوند.
- **حملات تزریق متقابل (Strict CSP)**: اعمال سرفصل‌های CSP مانع از اجرای اسکریپت‌های ثالث و نشت اطلاعات از طریق کانال‌های جانبی می‌شود.
- **فراموشی و رها شدن در پس‌زمینه**: گاوصندوق به‌صورت خودکار در صورت تغییر تب یا تایم‌اوت قفل می‌شود.

### ۲. مواردی که هیچ وب اپلیکیشنی نمی‌تواند در برابر آن‌ها محافظت کند:
- **دستگاه آلوده به بدافزار / Keylogger یا دستگاه روت‌شده**: در صورت وجود کی‌لاگر در سیستم‌عامل، گذرواژه هنگام تایپ توسط کاربر ممکن است ربوده شود.
- **افزونه‌های مخرب مرورگر (Malicious Browser Extensions)**: افزونه‌های نصب‌شده روی مرورگر که دسترسی به صفحات دارند می‌توانند محتوای صفحه را بخوانند. توصیه می‌شود کلیدبان را در پروفایل اختصاصی یا بدون افزونه اجرا کنید.
- **اسکرین‌شات و ضبط صفحه در سطح سیستم‌عامل**: مرورگرهای وب برخلاف برنامه‌های بومی اندروید/iOS (که فلگ `FLAG_SECURE` دارند) API عمومی برای مسدودسازی ضبط اسکرین‌شات توسط سیستم‌عامل ندارند. برای کاهش این ریسک، امکان مخفی‌سازی کدها تا زمان لمس در تنظیمات قرار داده شده است.
- **پاک‌کردن داده‌های سایت توسط کاربر (Clear Site Data)**: اگر کاربر حافظه کش و داده‌های سایت را پاک کند، گاوصندوق مرورگر حذف می‌شود. به همین دلیل برنامه مصرانه کاربر را به ایجاد نسخه پشتیبان رمزنگاری‌شده ترغیب می‌کند.

## 🚀 نصب و اجرای پروژه (Build & Run)

### پیش‌نیازها
- Node.js نسخه ۱۸ یا بالاتر
- npm یا pnpm

### راه‌اندازی محیط توسعه (Development)
```bash
npm install
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

### اجرای تست‌های واحد (Unit Tests)
شامل وکتورهای آزمایشی رسمی RFC 6238 برای SHA-1, SHA-256, SHA-512 و تست‌های رمزنگاری:
```bash
npm test
```

### ساخت نسخه نهایی (Production Build)
```bash
npm run build
```
خروجی در پوشه `dist/` قرار می‌گیرد که شامل تمام دارایی‌ها، فونت‌های وزیرمتن، آیکون‌ها و سرویس‌ورکر PWA است.

### اجرای سرور پیش‌فرض تولید
```bash
npx tsx server.ts
```

## 🌐 استقرار در سرور (Deployment)

کلیدبان یک سایت استاتیک (Static SPA) است و می‌تواند روی هر سروری که از HTTPS پشتیبانی کند مستقر شود (**HTTPS برای عملکرد دوربین و سرویس‌ورکر PWA الزامی است**).

### پیکربندی Nginx
فایل `nginx.conf` نمونه در ریشه پروژه قرار دارد. آن را در `/etc/nginx/sites-available/` قرار داده و دامنه و گواهی SSL خود را تنظیم کنید:
```nginx
# نمونه خلاصه
server {
    listen 443 ssl http2;
    server_name auth.yourdomain.com;
    root /var/www/kelidban/dist;
    index index.html;
    # شامل سرفصل‌های CSP و X-Content-Type-Options موجود در nginx.conf
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### پیکربندی Caddy
فایل `Caddyfile` نمونه در ریشه پروژه قرار دارد:
```caddy
auth.yourdomain.com {
    root * /var/www/kelidban/dist
    file_server
    try_files {path} /index.html
    # سرفصل‌های امنیت در Caddyfile پروژه تعریف شده‌اند
}
```
